Page 1 — Company Profile Layout goal: establish credibility and introduce RI YUE XING within the first three seconds of contact.

Layout Explanation

  • Header (top 20%): logo fixed left as the anchor readers scan first; company name right‑aligned in a single line so the strip stays low and doesn't compete with the hero.
  • Hero (middle 40%): one full‑bleed image carries the emotional weight of the page; headline and subhead sit inside a light scrim so type stays legible over photography of any tone.
  • Key advantages (bottom 30%): six equal‑width icon blocks in a single row create a scannable trust bar — the most common first read for a distributor deciding whether to stop at the booth.
  • Footer: thin strip, location + contact only — no competing message.

Recommended Image Positions

  • Hero: horizontal CNC machining action shot (sparks/coolant/turning) or a macro shot of small precision parts on a dark background — either works, pick whichever photographs sharpest at 297mm wide.
  • Logo: top‑left, vector format, generous clear‑space (do not crop against the hero grid line).
  • No secondary photography needed on this page — keep it to one dominant image.

Recommended Text Blocks

  • H1 (hero): "Precision CNC Machining Partner from Taiwan" — max ~45 characters, one line.
  • Subhead: "Specialized in Small Diameter Precision Components" — one line, lighter weight.
  • 6× advantage captions: 2–3 words each, no full sentences.
  • Footer: city/country + phone + email + website, single line.

Design Notes for Figma

Build as 3 auto‑layout frames stacked vertically (Header / Hero / Advantages) at fixed heights 20% / 40% / 30% + footer, so the ratio holds if copy length changes. Hero uses an image fill with a linear‑gradient overlay component (reuse across pages 1–5 hero/section headers for consistency). Advantage row = one component instanced 6× with icon + 2‑line caption; swap the row to 2×3 automatically at narrower breakpoints if a digital/social‑cut version is ever needed.

Page 2 — Precision CNC Machining Solutions Layout goal: prove manufacturing capability with a technical, credible reading order.

Layout Explanation

  • Left column (40%): capability list reads top‑to‑bottom like a spec sheet — icon + label pairs, no marketing copy, so an engineer can scan it in 5 seconds.
  • Right column (60%): a 1‑large + 2‑stacked photo collage gives visual variety without a rigid grid; large image = hero part type, two smaller images = supporting part families.
  • Bottom strip: three equal blocks (Materials / Precision / Process) act as a horizontal "spec bar" that buyers reference repeatedly — keep it visually distinct from the photo area above (light background fill) so it reads as reference data, not decoration.

Recommended Image Positions

  • Right‑large: small precision parts on neutral/dark background, top‑down or 3/4 angle.
  • Right‑upper‑small: connector parts, macro shot.
  • Right‑lower‑small: shaft components, macro shot, consistent lighting with the two above.

Recommended Text Blocks

  • Page title: "Small Precision Parts Manufacturing".
  • 4 capability line items (2–4 words each).
  • Materials: 5 material chips, single words.
  • Precision: one number ("±0.01 mm") + one label — no paragraph.
  • Process flow: 4 single‑word steps joined by arrows.

Design Notes for Figma

Right‑side collage should be one component with 3 image slots (1 large 1:1‑ish + 2 small 16:9) so photos can be swapped without breaking alignment. Bottom three blocks share one fixed height and a subtle divider (1px, 20% opacity) rather than heavy borders — keep the wireframe's dashed boxes but convert to hairlines in final art. Process‑flow arrows can be a small reusable "step chip" component reused on Page 4's inspection flow for visual consistency.

Page 3 — Industries We Serve Layout goal: let each buyer type self‑identify within seconds.

Layout Explanation

  • 2 columns × 3 rows, equal‑size cards — no visual hierarchy between industries since RI YUE XING serves them equally; a grid (not a list) signals breadth of application.
  • Each card: small icon/photo top, industry name, 1–2 typical component examples — consistent structure lets buyers compare across the page instantly.

Recommended Image Positions

  • Small icon or cropped photo per card (top ~55% of card height); photography preferred over icons if consistent lighting/background is available, otherwise use simple line icons for a cleaner technical look.

Recommended Text Blocks

  • Industry name: bold, 1 line.
  • Typical components: 1–2 short phrases, not full sentences.

Design Notes for Figma

Build one "industry card" component (image slot + name + component tags) and instance it 6×, so updating one card's style updates all. Keep card padding identical to Page 5's product cards for cross‑page rhythm. If six photos of consistent quality aren't available, fall back to a single icon set (outline style, 2px stroke) for visual consistency over photo realism.

Page 4 — Quality Assurance Layout goal: build procurement confidence through visible process, not claims.

Layout Explanation

  • Left (50%): vertical 3‑step flow diagram mirrors the process‑flow component from Page 2 for visual consistency across the brochure.
  • Right (50%): 2×2 equipment photo grid — evidence over adjectives; buyers trust seeing the actual measuring tools more than reading "strict QC."
  • Bottom strip: three document cards reinforce that documentation (traceability) is part of the offer, which matters most to purchasing managers and OEMs.

Recommended Image Positions

  • 2×2 grid: CMM, micrometer, height gauge, general measuring tools — real equipment photos, consistent angle/background across all four.

Recommended Text Blocks

  • 3 flow steps, 2–3 words each.
  • 3 document card labels only — no descriptive paragraphs; a thumbnail of each document (blurred/sample) can replace the label if available.

Design Notes for Figma

Reuse the Page 2 "step chip" component rotated to vertical for the flow diagram. Equipment grid = one component with 4 photo slots at equal aspect ratio. Document cards can later hold a faint document‑thumbnail image behind the label for realism; keep the card component identical in size to Page 3's industry cards so the grid rhythm feels intentional across the set.

Page 5 — Product Catalog Layout goal: close with tangible proof of capability and a direct next action.

Layout Explanation

  • 3×3 grid holds the 7 named product categories; the 8th cell becomes a soft call‑to‑action card ("Your Part Here?") and the 9th a logo/white‑space cell — this keeps the grid visually complete without inventing an 8th fake category.
  • Each card follows the same structure as Pages 3–4's cards (photo / name / spec line) so the brochure feels like one system by the final page.
  • Footer CTA is the last thing the reader sees — deliberately simple, one line + contact.

Recommended Image Positions

  • 7 product photos, one per named category, consistent background/lighting/angle (top‑down on neutral surface recommended for a technical catalog feel).

Recommended Text Blocks

  • Category name (bold, 1 line).
  • Material + Application as one short meta line each, not paragraphs.
  • Footer CTA: "Send us your drawing for evaluation." + email + website.

Design Notes for Figma

Single "product card" component reused 7× (photo slot + name + 2 meta fields); the CTA card is the same component with a color‑fill variant. Keep footer CTA typographically distinct (accent color) since it's the brochure's final conversion moment — it should read as an invitation, not another spec line.

Global Design Notes For the Figma build phase, applying across all 5 pages.

Grid & System

  • Canvas: 297×210mm (A4 landscape) or 1920×1080 (16:9) — build at 16:9 first, it maps cleanly to A4 with minor margin adjustment.
  • Consistent 8mm outer margin on every page.
  • Shared component library: header bar, hero overlay, icon block, step‑chip, card (photo+name+meta), footer bar.

Type & Color

  • One display weight for page titles, one body weight for meta/captions — avoid a third weight.
  • Neutral grayscale base + a single accent color (e.g. deep industrial blue) reserved for CTAs and key stats (±0.01mm, "Send us your drawing").
  • No gradients or consumer‑style color blocking — flat fills only.

Photography

  • Consistent lighting/background across all product and equipment photography — this matters more than photo count for a "precision" feel.
  • Prefer top‑down or 3/4 macro shots for parts; straight‑on shots for equipment.
  • Hero image (Page 1) is the one place for a dynamic/action shot — everything else should read as calm, technical, and repeatable.

Cross‑Page Consistency Checklist

  • Page header treatment (title style + rule line) identical on Pages 2–5.
  • Card component (photo/name/meta) shared by Pages 3, 4 (document cards), and 5.
  • Process/flow chip shared by Pages 2 and 4.
  • Footer bar shared by Pages 1 and 5 (contact info + CTA).

Explicitly Avoid

  • Large, unverifiable factory‑scale claims ("world's largest," etc.).
  • Dense paragraph copy anywhere — every text block above is capped at label/phrase length by design.
  • Stock‑photo consumer imagery, lifestyle photography, or playful iconography — this is a technical procurement document, not a retail flyer.
